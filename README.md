# 토익스피킹 준비 앱

「빠르고 확실한 마리아쌤 토익스피킹」(2024) 교재 내용을 바탕으로 만든 토익스피킹 준비용 웹앱(PWA)입니다.
휴대폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 설치해 오프라인에서도 쓸 수 있습니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| **홈** | 시험 D-day, 학습 진도, 최근 연습 기록 |
| **시험 정보** | 파트별 구성(문항·준비·답변 시간·평가 기준), 2022년 개편 내용, 등급 체계, 응시 주의 사항 |
| **접수 도우미** | 공식 사이트 바로가기, 시험일 입력 → D-day·성적 발표 예상일 계산, 캘린더(.ics) 추가, 접수 단계 체크리스트, 시험 당일 준비물 체크리스트 |
| **학습** | Part 1–5 교재 내용 (강세·끊어 읽기 표시 지문 16개, 사진 묘사 모범 답안 20개, Part 3 질문 유형·시제·만능 답변, Part 4 표 7종 + Q8–10 답안, Part 5 만능 답변 9개), TTS 발음 듣기, 학습 완료 표시 |
| **암기 카드** | 만능 콤보·주제별 만능 답변·묘사 문장·Part 4 표현·Part 5 문장을 카드로 암기 |
| **오늘의 학습** | 목표 등급·시험일·진도로 매일 할 일을 자동 구성 (시험 7일 전부터 집중 플랜), 실전 연습 기록으로 자동 완료 |
| **따라 말하기** | 원어민 음성(TTS)을 듣고 따라 말하면 음성 인식으로 놓친 단어 표시·정확도(%) 계산 |
| **실전** | 실제 시험과 같은 준비/답변 시간, 영어 음성(TTS) 안내·질문, 신호음, 마이크 녹음 → 내 답변과 모범 답안 비교, 준비 중 💡 힌트. 11문항 모의고사 또는 파트별·문제별 연습 |
| **학습 분석** | 연속 학습일, 최근 2주 학습량, 파트별 진도·답변 시간 활용률·따라 말하기 정확도, 약점 파트 추천 |

> 접수는 공식 사이트(TOEIC Speaking & Writing, YBM 한국TOEIC위원회)에서 직접 해야 합니다. 이 앱은 공개 API가 없는 공식 시스템을 대신하지 않고, 접수 과정을 안내·관리해 줍니다.

## 아이폰에서 사용하기

1. 배포 주소(GitHub Pages)를 아이폰 **Safari**로 엽니다.
2. 공유 버튼 → **홈 화면에 추가** → 앱처럼 실행됩니다 (한 번 열면 오프라인에서도 동작).
3. 실전 연습·따라 말하기를 처음 시작할 때 **마이크 허용**을 눌러 주세요.
4. 따라 말하기 음성 인식이 안 되면: 설정 → 일반 → 키보드 → **받아쓰기 켜기**, 설정 → Safari → 마이크 → 허용.
5. 무음 모드(옆 스위치)에서는 신호음·음성이 안 들릴 수 있어요.

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml` 이 푸시할 때마다 빌드해서 GitHub Pages 에 올립니다.
처음 한 번만 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔 주세요.
배포 주소: `https://lee-kyuyeon.github.io/TOEIC-Speaking-app/`

## 시험 형식 기준

2022년 6월 개편 형식(2026년 현재까지 추가 개편 공지 없음)을 따릅니다. 교재의 다음 오기는 바로잡아 반영했습니다.

- Part 2: 문항 수 1개 → **2개 (Q3–Q4)**
- Part 4: 표 읽기 시간 30초 → **45초**, 답변 시간 "Q7–Q8 15초 / Q9 30초" → **Q8–Q9 15초 / Q10 30초**
- "Part6 주제별 종류" → **Part 5**

Part 3·5 실전 문제는 교재의 예시 질문과 만능 답변 주제를 바탕으로 앱에서 구성했습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성 (상대 경로라 GitHub Pages 등 아무 경로에나 배포 가능)
npm run preview  # 빌드 결과 미리보기
```

- React 18 + TypeScript + Vite, react-router (HashRouter), vite-plugin-pwa
- 데이터: `src/data/` (`book.json`은 교재 PDF에서 추출, 나머지는 직접 구조화), 교재 이미지: `public/book/`
- 학습 진도·체크리스트·시험 일정은 브라우저 localStorage에만 저장되며, 녹음은 기기 밖으로 전송되지 않습니다.
